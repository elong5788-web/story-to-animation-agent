# 路线图

## 当前已完成 ✅

- [x] 调 DeepSeek 修饰提示词
- [x] 调 Seedance 生成视频
- [x] 短片/长片两种模式
- [x] 用户审查(可修改、可取消,不白花钱)
- [x] 密钥配置文件(config.properties)
- [x] ffmpeg 拼接

## 下一步(按优先级)

### 1. 参数调节 Skill
让时长、分辨率、运动强度等参数都可由用户控制,而不是写死。

### 2. 负面提示词 Skill
DeepSeek 修饰时自动附加负面词(模糊、水印、文字、畸形),排除坏结果。

### 3. 一致性控制 Skill(最难)
解决长片模式"镜头间不连贯"的问题。方向:
- Seedance 参考图/首尾帧接口(需先查 API 是否支持)
- 用同一张角色参考图喂给每个镜头

### 4. 质检诊断 Skill
生成后让 DeepSeek 多模态检查画质/内容,不合格自动重生成。

### 5. 后期处理 Skill
插帧、超分、去噪,提升精致度(可能需要引入外部工具)。

## 长期目标

对标"B 站发布的精致视频",把上面的 skill 逐个打通,让 agent 具备专业视频制作流程的完整能力。

> 原则:一个 skill 一个 skill 地补,每步都能跑、都有产出,不急功近利。
